## 1. 한 줄 소개와 핵심 방향

**신비한 동굴에 갇힌 용감한 몰티즈가 마법의 아이템을 모으고, 이상해진 동물들과 싸우며,
동굴 가장 깊은 곳의 크리스탈 킹을 물리치고 혼자 탈출하는 3D 액션 로그라이크.**

| 기둥 | 뜻 |
|---|---|
| 신비로운 모험 | 무서운 공포보다 아름답고 신기한 동굴을 탐험하는 재미 |
| 아이템 전투 | 몰티즈는 전사가 아니라 도구를 영리하게 쓰는 모험가. 적마다 잘 듣는 아이템이 있다 |
| 매번 다른 동굴 | 방 배치·보물·상점이 탐험마다 바뀐다. 실패해도 도감과 해금이 남는다 |
| 혼자 탈출 | 동물을 구하는 게 목표가 아니다. 몰티즈가 직접 보스를 물리치고 빠져나간다 |

플레이어가 계속 품어야 할 질문: **"이 동굴의 가장 깊은 곳에는 도대체 무엇이 있을까?"**

| 항목 | 결정 |
|---|---|
| 장르 | 3D 액션 로그라이크 (싱글 플레이) |
| 시점 | 쿼터뷰 (Island의 디아블로식 카메라) |
| 이동 | 3D 공간 자유 이동, 클릭 이동 |
| 전투 | 실시간 액션, 커서 방향으로 아이템 사용 |
| 지역 | 4개 (이끼 → 버섯 → 얼음 → 수정의 심장) |
| 한 판 길이 | `[call]` 전체 15~25분, 지역당 4~6분. MVP는 5분 |
| 플랫폼 | 웹 브라우저 (PC 마우스 + 휴대폰·태블릿 터치) |

## 2. 세계관과 스토리

### 2.1 프롤로그 — 사라진 몰티즈

![프롤로그](images/02-prologue.png)

아주 먼 지구 어딘가에 하얗고 귀여운 몰티즈 한 마리가 살고 있었어요.
몰티즈는 언제나 새로운 곳을 찾아다니는 용감한 모험가였어요.

어느 날 숲속을 탐험하던 몰티즈는 땅에서 이상한 발자국을 발견했어요.
발자국을 따라가자 거대한 동굴 입구가 나타났어요.

"멍? 여기는 어디지?"

동굴에 들어간 순간 — **쿠구구궁!** 바닥이 무너지고 몰티즈는 깊은 지하로 떨어졌어요.
SOS를 보냈지만 아무도 대답하지 않았어요.

어둠 속에서 수많은 눈동자가 빛나기 시작했어요. 늑대, 여우, 토끼, 사슴…
이상하게도 육식동물이든 초식동물이든 모두 몰티즈를 공격했어요.

몰티즈는 바닥에 떨어져 있던 낡은 망치와 물총을 집어 들었어요.

"좋아! 반드시 여기서 나갈 거야!"

`[call]` (2026-11-05 만든 그대로, 사용자: "카드로 이모지와 나오는 것도 어색") 프롤로그는 **게임 엔진 안의 3D 컷신**이다(약 42초, `src/ui/intro.js`, 시간표 `introTimeline.js`). 동굴 세계와 따로, 인트로만을 위한 작은 세트를 게임 렌더러로 그리고 끝나면 모두 치운다. 진짜 몰티즈(절차적 모델과 그 애니메이션)가 나오고, 위아래 검은 띠(레터박스), 화면 아래 Jua 글꼴 자막이 부드럽게 타자로 찍힌다. 신비롭지만 무섭지 않게.

### 2.2 동굴의 비밀

- 동굴 깊은 곳에는 공중에 뜬 **보라색 마법 수정**이 있다. 수정의 힘이 동굴 동물들을 사납게 만든다.
- 깊이 들어갈수록 수정의 힘이 강해지고 동물도 강해진다 (= 난이도 상승의 이야기상 이유).
- 수정의 힘을 지키는 것이 최종 보스 **크리스탈 킹**이다.
- 벽에 새겨진 글자와 **황금 목걸이**가 길잡이가 된다 (§6.4).
- 동물들이 *왜* 공격했는지는 엔딩에서 다 설명하지 않는다. 후속작을 위한 미스터리로 남긴다.

### 2.3 엔딩 — 혼자 탈출

![엔딩](images/03-ending.png)

크리스탈 킹을 물리치면 동굴 전체가 빛나기 시작한다. 수정의 힘이 사라지자 벽이 흔들리고 숨겨진 출구가 열린다.
몰티즈는 마지막 힘을 내어 출구로 달린다. (무너지는 동굴 탈출 구간, 약 20초)

눈부신 햇빛. "멍멍! 드디어 탈출했다!"
몰티즈는 거대한 동굴을 한 번 돌아보고, 새로운 모험을 찾아 떠난다.

**THE END** — 크레딧 후, 동굴 안쪽에서 작은 보라색 조각 하나가 반짝인다. (Island의 "THE END?"와 같은 장치)

`[call]` (W4, 2026-11-02 만든 그대로) 크리스탈 킹이 잠들면 별 하나, 하트 가득, 그가 부른 동물들도 잠든다. 머리 위 거대한 수정 심장의 보랏빛이 3초에 걸쳐 따뜻한 빛으로 바래고, 동굴이 두 번 크게 흔들리고("숨겨진 출구가 열려요!"), 심장의 단에서 화면 위쪽으로 **수정 다리**가 판 하나씩 생겨나 **수호자의 단**(모아이 둘이 지키는 −112 단)으로 이어진다. 탈출: 다리(70 m) → 수호자의 단 → 터널 입구(Polyfork 터널 포털) → 위로 오르는 골짜기 길(−112 → −96) → **햇빛 구멍**. 앞쪽에 바위가 떨어지고(빨간 원 먼저, 반 칸, 다리 위에는 없음), 화면 위에 부드러운 시계 "☀️ 햇빛까지 달려요! 60"이 줄어든다. 시계가 다 돼도 실패는 없고 바위가 조금 더 자주 떨어질 뿐. 탈출 중 쓰러지면 심장의 단에서 하트 가득으로 깨어 다시 달린다. 햇빛에 닿으면 엔딩: 빛 → "멍멍! 드디어 탈출했다!" · 지금까지 모험한 시간 · (처음이면) ⭐ 크리스탈 킹 · THE END · 크레딧 · 보라색 조각 → **결과 화면**(모험한 시간 · 모은 별 · 도감 n/N · 재운 대장 4/4 · 재운 동물 · 수정 조각, 재운 대장들) → **계속 탐험하기**: 캠프에서 다시, 세계는 그대로 열려 있음(탈출 뒤 탐험). 처음 화면으로 가도 "이어 하기". 탈출은 `wins`(타이틀 🏁)와 `world.won`에 저장된다.

## 6. 전투와 아이템

### 6.1 전투 규칙

- 몰티즈는 움직이면서 공격할 수 있다.
- 적의 모든 공격에는 준비 동작과 바닥 범위 표시가 있다. 범위 밖으로 나가면 맞지 않는다.
- 아이템마다 사용 속도와 재사용 대기시간이 다르다.
- 적마다 잘 듣는 아이템이 있다 (§3.2). **잘 듣는 아이템으로 기절시키고 → 망치로 마무리**가 기본 흐름.

### 6.4 황금 목걸이

v1에서 스토리를 여는 아이템이었다가 v2에서 빠졌던 것을 다시 넣는다. `[call]`

- **첫 탐험 때 이끼 동굴의 첫 방**에서 줍는다. 줍는 순간 동굴 벽에 글자가 빛난다:
  *"동굴의 가장 깊은 곳에 닿는 자만이 빛을 볼 수 있으리."*
- 한 번 얻으면 영구히 가지고 있다 (도감 해금).
- 각 지역의 **비밀 문(수정 문)** 앞에 가면 목걸이가 빛나며 문이 열린다 → 비밀 방(§7.3).
- 엔딩에서 출구 문을 여는 열쇠가 된다.
- `[call]` (W5) 큰 세계의 **비밀 구역** 넷(지역마다 하나): 이끼 낀 바위 벽처럼 보이는 수정 문이 짧은 통로를 막고 있다. 가까이 가면 "냄새가 나요… 1번!" → **냄새 맡기(1)**가 닿으면 문이 드러나고(✨, 수정이 빛남, 지도에 표시, 저장) → 목걸이를 가진 채 7 m 안에 가면 목걸이가 빛나며 문이 가라앉는다(저장). 처음 열면 **별 하나 + 도감 비밀 쪽**(벽의 옛 글자). 안에는 보라 수정 뚜껑 상자(탐험마다 다시 참): 토끼굴 초원 뒤 = 망치 강화 보석, 버섯 숲 왼쪽 위 = 물총 강화 보석, 얼음 고개 옆 = 전설 갑옷, 서쪽 유적 뒤 = 강화 보석(낮은 쪽). §14 #69

### 6.5 아이템 등급

같은 아이템도 등급에 따라 성능이 다르다. 보물 상자·상점에서 얻는다. 한 판이 끝나면 처음 등급으로 돌아간다.

| 등급 | 테두리 | 예: 망치 | 예: 물총 |
|---|---|---|---|
| 일반 | 흰색 | 기본 | 기본 |
| 희귀 | 파란색 | 공격 범위 +50% | 두 줄기 발사 |
| 전설 | 금색 | 휘두를 때마다 작은 충격파 | 물폭탄 (범위 밀어내기) |

`[call]` (W5, 2026-11-02) 들어간 모습 (`src/combat/grades.js`, 수치는 `data/items.js` `grades`):
- 망치 희귀 = 사거리 2 → 3 m. 전설 = 사거리 3 m + 맞힐 때마다 작은 충격파(반지름 2 m, 피해 ⅓, 밀어내기 1.1 m; 세 번째 연속 공격의 큰 충격파는 그대로).
- 물총 희귀 = 두 줄기(9° 벌어짐, 물은 한 발 값). 전설 = 두 줄기 + 닿는 곳마다 물폭탄(반지름 2.6 m 안의 동물을 밀고 적심).
- 얻는 곳: 보물 상자의 **강화 보석**(큰 세계에서만, 깊을수록 잘 나옴: 지역 1~4 가중치 ×0.6 / ×1 / ×1.4 / ×1.8, 둘 다 전설이면 안 나옴), 박쥐 상인(망치 강화·물총 강화: 희귀 8조각, 전설 14조각), 비밀 구역 상자.
- HUD 망치·도구 칸의 테두리 색(일반 흰색, 희귀 파랑, 전설 금빛 반짝임)과 작은 "희귀"/"전설" 글자. 휴대폰은 🔨·💧 버튼 테두리.
- **쓰러지면 망치·물총 등급은 일반으로 돌아간다**(이 표의 "한 판" = 큰 세계에서는 쓰러질 때까지). 캠프로 돌아와 새 탐험이 시작돼도 등급은 남는다. 갑옷은 등급째 줍는 물건이라 그대로 남는다(W3부터). §14 #67

### 7.2 동굴 만들기 — 모듈 조합

방을 완전히 랜덤으로 생성하지 않고, **미리 만든 공간 조각(모듈)을 랜덤하게 이어 붙인다.**
지역마다 모양은 같고 재질·소품·조명만 다르게 입힌다.

| 모듈 | 설명 |
|---|---|
| Entrance | 지역 입구 (이전 지역에서 내려오는 길) |
| RoomSmall | 작은 전투 공간 (적 2~3) |
| RoomLarge | 넓은 전투 공간 (적 4~6, 기둥·바위 엄폐물) |
| Corridor | 좁은 통로 (기습, 함정) |
| Treasure | 보물 상자가 있는 공간 |
| Rest | 휴식 공간 (모닥불 대신 빛나는 샘) |
| Shop | 상인 (`[call]` Island의 앵무새 Polly 대신 **박쥐 상인**) |
| Secret | 목걸이로 여는 비밀 공간 |
| Boss | 보스 전용 원형 경기장 |

- `[call]` (2026-11-01 고침) 한 지역은 **하나의 큰 지도**로 한 번에 지어진다. 방 = 넓은 동굴 광장, 방과 방은 넓고 짧은 길로 이어져 화면 전환 없이 걸어간다. 위 모듈 표의 방 종류는 광장의 종류다(모듈 조각 대신 광장 모양을 시드로 만든다).
- 광장을 정리하면(동물을 모두 재우면) 수정 조각이 날아오고 가끔 약초. 보통 전투는 길을 막지 않는다.
- 갈림길에서는 **갈라지는 넓은 길 두 개** 중 하나를 고른다. 길 입구의 표지판이 그 길 끝 광장의 종류를 알려 준다 (⚔ 전투 / 🎁 보물 / 💧 휴식 / 🪙 상점 / ❓ 모름). 두 길은 다음 광장에서 다시 만난다.

### 7.3 방 종류

| 방 | 하는 일 |
|---|---|
| 전투 방 | 동물들과 전투, 끝나면 수정 조각과 가끔 약초 |
| 보물 방 | 보물 상자 → 아이템 또는 등급 업 |
| 휴식 방 | 하트 2칸 회복, 갑옷 다시 채움, 약초 1개 |
| 상점 방 | 수정 조각으로 아이템·약초·등급 업 사기 |
| 비밀 방 | 목걸이로 엶. 희귀 이상 아이템 또는 도감 페이지 |
| 보스 방 | 지역 보스. 이기면 다음 지역 입구가 열리고 하트 완전 회복 |

### 7.4 한 지역의 흐름 (예)

```
입구 → 전투 → [전투 | 보물] → 전투 → [휴식 | 상점] → (비밀 방은 어딘가 벽 뒤) → 보스
```

`[call]` 지역마다 방 5~6개 + 보스. 갈림길 2번.

`[call]` M4 방 생성 규칙 (옛 `src/dungeon/generator.js`, W7에서 삭제):
- 길은 입구와 보스 사이의 칸(slot) 줄이다. 칸 하나에 방 하나, 갈림길이면 방 둘. 갈림길은 **그 앞 방의 문 두 개**이고, 어느 문으로 가도 다음 칸으로 이어진다 → 어느 길이든 방 수가 같아서 "방 n/N"이 늘 맞다.
- 입구는 동물 없는 작은 방(문이 바로 열림). 입구 다음 첫 방은 쉬운 전투(작은 방, 늑대 2마리), 갈림길이 아니다.
- 갈림길의 두 문은 서로 다른 종류. 어느 길에서도 휴식 방 두 번 연속·보물 방 두 번 연속은 없다. 어느 길이든 보물 방이 하나 이상. 보스 바로 앞 칸에는 늘 휴식 방이 있다(갈림길이면 한쪽).
- 종류 가중치 전투 6 · 보물 2 · 휴식 1.5 · 상점 0 · 비밀 0 (상점·비밀은 M6에서 가중치만 올리면 들어감). 전투 방 늑대 수: 작은 방 2~3, 큰 방 3~4 (§7.2의 큰 방 4~6은 동물 종류가 늘면).
- ~~방은 하나씩 짓는다(문을 지나면 페이드 → 다음 방)~~ → 2026-11-01 사용자 요청으로 바뀜: 아래 "이어진 동굴 지도".
- 보스 방(M5): 둥근 경기장에 거대 토끼 대장(§3.3). 대장이 잠들면 동굴이 흔들리고 목걸이가 빛나며 🏁 수정 문이 열린다 → 탈출 통로 → 엔딩 → 승리 결과 화면.
- M5: 동물이 깨어난 뒤 1.5초 동안은 몰티즈를 알아채지 못하고(숨 돌릴 틈), 동물 자리는 모두 광장의 길 입구에서 9 m 이상. 첫 방은 늑대만, 그 뒤 전투 방은 늑대·토끼 반반. 정리한 광장의 수정 조각·약초는 몰티즈에게 날아오고, 다른 광장으로 갈 때 남은 것은 저절로 줍는다.

`[call]` **이어진 동굴 지도** (2026-11-01, 사용자: "스테이지가 너무 작다" → "방 형태가 답답하다" → "카메라가 가깝고 큰 동굴 느낌이면", 옛 `src/dungeon/mapLayout.js`·`caveMap.js`·`dungeon.js`, W7에서 삭제):

- **이끼 계곡**(1지역, 약 430 × 300 m): 입구 싱크홀(0 m, 햇빛 기둥) → 위 단구(−8) → 가운데 단구(−16) → 아래 단구(−24), 단구 사이는 경사로. 계단식 폭포: 싱크홀 샘 → 웅덩이 → 폭포 → 개울 → 웅덩이 … 마지막 폭포는 큰 골짜기로 떨어진다(물줄기가 절벽 밖으로 뿜어져 위에서 보인다). 큰 골짜기(−70) 위로 Polyfork 돌다리(4칸, 94 m)가 캠프 앞 돌 교두보(−24)로 건너고, 경사로로 캠프에 내려간다. 거대한 바위 기둥(sea-stack)이 골짜기에서 솟아 다리를 받친다. 오른쪽 아래 단구는 옛 광산(갱도 탑·레일·수레), 협곡 경사로를 내려가면 토끼굴 초원(−30)의 둥근 경기장.
- **캠프**(−30): 빛나는 샘(하트 모두 회복, 약초는 탐험마다 하나), 박쥐 상인(상점, W5 등급 강화), 도감 돌(도감 책, §8.4), 별 제단(영구 해금·꾸미기, §8.3), 횃불. 앞 가장자리에서 샘물이 골짜기로 떨어지는 폭포(계곡에서 마주 보임), 뒤쪽 발코니에서 수정의 심장 구덩이가 보랏빛으로 내려다보인다.

- **수정 가시**(`CRYSTAL_SPIKE`): 협곡과 유적의 몇 곳에서, 그 안에 있는 동안 3.2초마다 발밑(조금 비켜서)에 보라 원 + 빨간 테가 1.35초 자라다가 수정 가시가 솟는다(반 칸). 걸어 나가면 안 맞는다.
- **깡충 뛰기**(`hops`, 걷는 격자의 점프 연결, 두 방향): 떠 있는 바위는 걷는 격자의 두 번째 층(다리 상판처럼 `islands`), 가장자리마다 보이지 않는 벽이 있어 떨어지지 않는다. 바위끼리는 걸어서 이어지지 않고 깡충으로만(동물은 뛰지 않아 바위에 오지 못함). 뛰는 시간 0.5 + 거리/24 초, 높이 2.2 m, 9~20 m.
- **미끄러운 얼음**(`world.js` `SLIP`): 호수와 경기장의 맨 얼음에서는 몰티즈가 미끄러진다: 가고 싶은 쪽으로 천천히 돌고(초당 3.2), 멈추면 2 m쯤 더 미끄러지고, 구르기는 6 m쯤 더 간다(`player/movement.js` `slideVelocity`). 클릭한 곳에는 미리 손을 놓아 거의 그 자리에 선다. 길찾기는 얼음을 조금 꺼린다(칸마다 +0.35). 동물도 밀리면 얼음에서 약 3배 미끄러지고, 사슴의 돌진은 얼음에서 조금 더 간다. 절벽 끝의 보이지 않는 벽이 있어 떨어지지는 않는다.
- **고드름 함정**(`ICICLE`): 얼음 고개·얼음 동굴 통로·얼어붙은 폭포 아래에서, 그 안에 있는 동안 2.6초마다 몰티즈 발밑(조금 비켜서)에 그림자(빨간 테 검은 원)가 1.35초 자라다가 고드름이 떨어진다(반 칸). 걸어 나가면 맞지 않는다.

## 8. 로그라이크 구조와 난이도

### 8.1 한 판의 흐름

~~동굴 입장 → 이끼 동굴(방 5~6개 + 거대 토끼 대장) → 버섯 동굴 → 얼음 동굴 → 수정의 심장(크리스탈 킹) → 탈출 → 엔딩~~

`[call]` (W1, 2026-11-02) **탐험 루프**: 새 게임 → 프롤로그 → 싱크홀로 떨어짐 → 목걸이 → 계곡 탐험 → 캠프 발견 → 캠프에서 준비하고 나감 → 탐험 → 돌아오거나 쓰러짐 → 캠프 → … 지역 순서 1 → 2 → 3 → 4, 보스를 재우면 다음 지역 길과 캠프로 오는 지름길이 열린다. 캠프로 돌아올 때마다(밖에 나갔다 오면) **새 탐험**: 새 시드로 조우 자리가 다시 채워진다. 진행(캠프 발견·열린 문·재운 보스·가 본 지도·가진 것)은 저장되고, 다음에 열면 캠프(캠프를 못 찾았으면 입구)에서 이어 한다. 메뉴의 “처음부터”는 세계만 처음으로(도감·별은 남음).

### 8.2 쓰러지면

- ~~하트가 0이 되면 탐험 실패. "몰티즈가 지쳐서 잠들었어요…" → 캠프(동굴 입구)로 돌아온다.~~
- ~~이번 판에서 얻은 아이템, 등급, 수정 조각은 잃는다.~~
- `[call]` (W1) 하트가 0이 되면 쓰러졌다가 **캠프에서 깬다**(캠프를 아직 못 찾았으면 동굴 입구). 하트는 가득, **이번 탐험에서 주운 수정 조각의 절반(내림)을 잃는다**(캠프에서 가지고 나간 조각은 안전). 아이템·약초는 그대로. 새 탐험이 시작된다.

### 8.3 영구 성장

`[call]` 캠프에서 **별**로 해금한다. 별은 처음 해낸 일(보스 첫 처치, 비밀 방 첫 발견, 도감 완성 등)로 얻는다.

`[call]` (W5) 들어간 모습: 캠프의 **별 제단**을 누르면 창이 열린다(세계가 멈춤, Esc·닫기). 별은 모두 11개: 대장 넷(처음 재울 때) + 비밀 구역 넷(처음 열 때) + 도감 반(12/24)·전부(24/24) + 엔딩 뒤 보라 조각. 해금도 모두 합쳐 11개라 모든 일을 하면 모두 열린다. 쓰러져도, "처음부터"도 해금은 남는다(저장 `unlocks`·`wear`). 탐험이 시작될 때(캠프로 돌아올 때, 깨어날 때) 적용되고, 사는 순간에도 바로 적용(새 하트는 채워진 채).

|---|---|---|
| ❤️ 하트 +1 | 2 | 최대 하트 5 → 6 |

### 8.4 도감

동물·아이템·보스를 처음 만나면 도감 페이지가 열린다. 동물 페이지에는 공격 패턴과 **약점 아이템**이 표시된다.
도감은 딸이 직접 쓴 설명 문구를 넣기 좋은 곳이다.

`[call]` (W5) 캠프 도감 돌의 **도감 책**(`src/ui/codex.js`, 글은 `src/data/codex.js`): 탭 다섯 — 동물 7 · 대장 4 · 물건 8 · 비밀 5(비밀 구역 넷 + 보라 조각 "다음 모험…") · 콤보 5. 칸마다 그 모델의 작은 그림(Polyfork 동물, 절차적 보스·물건을 작은 렌더러로 한 번 그림), 아직 못 본 것은 **검은 실루엣 + ?**. 칸을 누르면 오른쪽(좁은 화면은 아래)에 큰 그림·사는 곳·짧은 설명·약점(동물)·이기는 법(대장). 위에 n/24와 막대, 별 표시(12개 → ⭐, 24개 → ⭐). 지금 글은 아빠가 쓴 임시 글: 딸의 글로 바꾸기 좋다(`data/codex.js`).

### 8.5 난이도

쉬움부터 점점 어려워진다. 숫자만 올리지 않고 **새 공격과 환경 요소**를 더한다.

| 지역 | 적 체력 | 적 공격력 | 추가되는 것 |
|---|---|---|---|
| 이끼 동굴 | ×1.0 | ×1.0 | 기본 공격만 |
| 버섯 동굴 | ×1.25 | ×1.15 | 독 지형, 숨는 적 |
| 얼음 동굴 | ×1.5 | ×1.3 | 미끄러운 바닥, 얼음 함정 |
| 수정의 심장 | ×1.8 | ×1.5 | 레이저, 소환, 모든 적 섞임 |

**도움 장치** (억울한 실패 줄이기):
- 처음 들어간 지역에서는 적의 공격 속도를 조금 낮춘다.
- 하트 25% 이하이면 약초가 나올 확률이 높아진다. `[call]` 상자의 약초 가중치 ×3, 전투 방 정리 약초 확률 ×3(최대 75%) (`ASSIST`, `src/data/items.js`).
- 보스의 공격 범위는 항상 바닥에 미리 표시한다.
- 같은 보스에게 연속으로 지면 다음 판에 약초를 1개 더 준다. `[call]` (W5) 보스 싸움 중 쓰러진 횟수를 보스마다 세고(`bossLosses`), **두 번째부터** 깨어날 때 약초 하나 더(주머니에 자리가 있으면, 박쥐 상인이 챙겨 줌). 그 보스를 재우면 다시 0.
- 어려운 구간 앞에는 휴식 방을 둔다.

## 9. 아트와 사운드

- **스타일:** Island와 같은 귀여운 로우폴리 + 외곽선. 무섭기보다 신비롭게.
- **모델:** Polyfork 로우폴리 모델(동물, 버섯, 바위, 수정 등)을 CDN에서 불러온다. 몰티즈와 카탈로그에 없는 것은 코드로 만든다.
- **색:** 지역마다 대표 색 — 이끼 초록 / 버섯 보라·주황 / 얼음 하늘색 / 수정 진보라.
- **빛:** 동굴이라 어둡다. 몰티즈 주변의 부드러운 빛, 빛나는 이끼·버섯·수정이 주 광원.
  (K1 부드러운 룩, 2026-11-05) 햇빛이 아니라 "신비한 동굴 빛": 주 빛(키 라이트)은 카메라 쪽 앞-왼쪽 위(고도 약 50°)에서 와서
  카메라를 보는 면(절벽 앞면·몰티즈 얼굴·소품)이 밝고, 그림자는 화면 위-오른쪽으로(뷰어에서 멀어지게) 떨어진다. 그림자는
  부드럽고 옅다(완전히 검지 않고 푸른 기). 하늘 쪽 채움빛은 시원한 라벤더 블루, 땅 쪽은 따뜻한 흙색 — 옆면·아랫면이 검게
  뭉개지지 않는다. 지역마다 안개 색과 수정·버섯·얼음 팔레트는 그대로. 후처리: 은은한 AO(물건이 땅에 닿는 곳에 푸른 접촉 그림자),
  블룸은 빛나는 것만(수정·빛나는 버섯·반딧불·빛기둥·주인공 고리), 색 보정(채도 약간↑, 어두운 곳을 라벤더 블루로 살짝 들어 올림,
  밝은 곳은 조금 따뜻하게), 비네트. 톤매핑 없음. 화질 세 단계(성능, 2026-11-07): **높음**(모든 효과, 화면 픽셀 최대 1.5배, 그림자 지도 2048) / **중간**(AO 없음, 블룸·보정·비네트, 픽셀 1.25배, 1024) /
  **낮음**(보정·비네트만, 픽셀 1배, 1024). 휴대폰·작은 태블릿은 처음부터 낮음, 메뉴의 "화질: 높음/중간/낮음"으로 바꾸고 이 브라우저에 남음, 주소 `?q=`가 우선.
  컴퓨터가 버거우면(플레이 몇 초 뒤 프레임 중앙값 20 ms 넘음) 스스로 한 단계 낮추고 "부드럽게 하려고 화질을 낮췄어요 (메뉴에서 바꿀 수 있어요)"라고 말한다
  (올리지는 않음, 고른 단계는 그대로). `?perf=1`이면 성능 패널(프레임·CPU·드로 콜·스위치).
  인트로 컷신은 같은 렌더러로 그리되 효과 없이(장면마다 맞춘 빛 그대로).
- **사운드:** Island의 합성 효과음 방식. 물방울, 메아리, 동물 울음, 아이템 효과음. 지역별 배경 음악.
  `[call]` (W5) 모두 WebAudio 합성(파일 없음, `src/audio/sound.js`): 8분음표 시퀀서에 분위기마다 템포·음계·화음 진행·부드러운 패드·아르페지오·리드·북. **캠프**(따뜻하고 느림) · **이끼 계곡**(밝은 5음계) · **버섯 숲**(통통 튀는 도리아) · **얼음 호수**(느린 리디아, 종소리) · **수정의 심장**(신비한 단조) · 쫓길 때 · 보스 넷 각자의 주제(대장: 통통, 여왕: 살금살금, 얼음 곰: 묵직, 킹: 웅장한 화성 단조) · 탈출 · 엔딩(해 뜨는 장조). 메뉴에 **음악·효과음 음량** 막대(이 브라우저에 저장), 소리 끄기. 소리는 첫 클릭·터치·키에 깨어난다.
- **글꼴:** Jua (Island와 같음).

### 10.2 시작 방법

`[call]` Island 저장소를 복사해서 시작하고, 섬 전용 코드를 걷어 낸다. 공용 패키지로 나누는 것은 두 게임이 모두 안정된 뒤에 생각한다.

**그대로 쓰는 것:** `src/player/`(isoCamera, movement, player), `src/systems/pointer.js`·`nav.js`, `src/physics/`, `src/ui/`(hud, labels, screens, touch), `src/audio/`, `src/entities/outline.js`·`puppet.js`, `src/core/state.js`, `scripts/e2e.mjs`, 빌드·배포 설정.
**걷어 내는 것:** 섬 지형(`map.js`, `island.js`, `regions/*`), 섬 몬스터, 퀘스트, 멀티플레이(`src/net/`, `coop.js` — 이번 게임은 혼자 탈출).
**참고하는 것:** Island의 `src/world/cave.js`(광산 동굴: 천장 숨김, 동굴 조명; 옛 동굴 판에서 쓰다가 W7에서 삭제).

### 10.5 핵심 구현 요구사항

| 시스템 | 구현 |
|---|---|
| 클릭 이동 | Island의 `pointer.js` + A* `nav.js` (땅만 클릭 판정, 못 가는 곳은 가장 가까운 곳까지) |
| 충돌·물리 | Rapier 캐릭터 컨트롤러 |
| 공격 판정 | 망치: 부채꼴 범위 / 물총·덩굴: 투사체 + Rapier 레이캐스트 |
| 방 생성 | 시드 RNG → 방 그래프(순수 함수, 테스트 가능) → 모듈 빌더가 3D로 조립 |

## 11. 개발 로드맵

Island와 같은 방식: 단계마다 **만들기 → 브라우저(헤드리스)로 확인 → 기획서와 대조**.

| 단계 | 내용 | 완료 조건 |
|---|---|---|
| **M0. 뼈대** | Island 복사, 섬 코드 걷어 내기, 빈 동굴 방 하나, 빌드·배포 | `npm test`·`npm run build` 통과, 빈 방에서 클릭 이동 |
| **M1. 몰티즈와 동굴** | 몰티즈 모델·애니메이션, 동굴 방 모듈 2개, 천장 숨김·벽 반투명, 구르기 | 동굴을 자유롭게 돌아다닌다 |
| **M2. 전투** | 망치, 물총(물통 구슬), 늑대 AI, 하트·피격·무적, 쓰러짐 | 늑대와 실시간 전투가 된다 |
| **M3. 아이템** | 덩굴, 방패, 약초, 보물 상자, 우클릭 도구 바꾸기, HUD | 여러 아이템을 섞어 싸울 수 있다 |
| **M4. 로그라이크** | 방 생성기, 갈림길 문, 휴식·보물 방, 결과 화면, 다시 하기 | 매번 다른 동굴을 탐험한다 |
| **M5. 이끼 동굴 완성 (MVP)** | 토끼, 거대 토끼 대장, 출구 탈출, 황금 목걸이 | 시작부터 첫 보스 처치 후 탈출까지 5분 플레이 |
| **M6. 버섯·얼음 동굴** | 여우, 두더지, 사슴, 곰, 탈, 갑옷, 상점, 보스 2종 | 3개 지역 연속 플레이 |
| **M7. 수정의 심장과 엔딩** | 크리스탈 킹, 무너지는 동굴 탈출, 엔딩, 크레딧 | 처음부터 엔딩까지 완주 |
| **M8. 성장과 다듬기** | 도감, 별·해금, 아이템 등급·조합, 비밀 방, 음악, 휴대폰, 밸런스 | `full.js` 헤드리스 완주 + 딸 플레이 테스트 |

> 2026-11-02: M6~M8은 큰 세계 재설계 W1~W5로 대신했다(tasks/20261102-world-redesign-todo.md). W5에서 M8의 모든 기능이 들어갔고 `full.js`가 처음부터 엔딩·보라 조각까지 헤드리스로 완주한다. 남은 것은 딸의 플레이 테스트.

## 12. 테스트 시나리오

Island처럼 단위 테스트(Vitest)와 헤드리스 시나리오(`scripts/scenarios/`)로 확인한다.

| 테스트 | 성공 기준 |
|---|---|
| 이동 | 클릭한 곳 0.3 m 안에 도착, 벽을 통과하지 않음, 못 가는 곳은 가장 가까운 곳까지 |
| 카메라 | 벽 뒤에서도 몰티즈가 항상 보임 (천장 숨김, 벽 반투명) |
| 망치 | 적 클릭 → 다가가서 휘두름, 체력 1 감소 |
| 물총 | 우클릭 방향으로 발사, 적이 밀려남, 물통 감소 후 다시 참 |
| 덩굴 | 맞은 늑대가 3초 동안 멈춤, 젖으면 5초 |
| 늑대 AI | 발견 → 추적 → 공격 범위 표시 → 공격 → 빈틈 |
| 구르기 | 구르는 동안 피해 없음 |
| 하트 | 피격 시 반 칸 감소, 0.7초 무적, 0이면 결과 화면 |
| 약초 | 하트 2칸 회복, 최대치 넘지 않음 |
| 방 생성 (단위) | 같은 시드 → 같은 동굴, 모든 방이 보스 방까지 이어짐, 갈림길 2개 |
| 보물 | 상자를 열면 아이템 획득, HUD 갱신 |
| 보스 | 페이즈 전환, 공격 범위 표시, 착지 빈틈에 망치가 맞음 |
| 엔딩 | 보스 처치 → 출구 열림 → 탈출 → 엔딩 화면 |
| 완주 (`full.js`) | 새 게임 → 엔딩까지 헤드리스 한 번에 통과 |
