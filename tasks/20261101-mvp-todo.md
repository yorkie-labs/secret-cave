# 2026-11-01 · Secret Cave MVP (GDD M0 → M5)

Goal (user, /goal): 서브에이전트로 한 단계씩 구현 → 리뷰 → 다음 단계. MVP(M5)까지 반복.

Source of truth: [docs/GDD.md](../docs/GDD.md). `[call]` 항목은 GDD §14의 임시 결정을 따른다.
Base: Scary Island (`yorkie-labs/scary-island`) 복사 후 섬 전용 코드 제거.

## 진행 방식
각 마일스톤: 서브에이전트 구현 → `npm test` + `npm run build` + 헤드리스 시나리오 → 메인 세션 리뷰(코드 읽기 + 직접 실행) → 수정 → 다음.

### 2026-11-01 · M1 몰티즈와 동굴
- 몰티즈 `entities/maltese.js`: 절차적 SD 모델(큰 머리, 작은 몸), 털은 "퍼프"(중심 공 + 표면 작은 공들을 한 지오메트리로 합침 → 외곽선이 털 가장자리만 따라감), 털 묶음 3개로 된 긴 귀, 검은 눈·코·분홍 혀, 정수리 털과 분홍 리본, 카키 조끼(앞이 트인 껍데기)·주머니·옆 가방·끈, 나무 망치, 물총(쏠 때만). 하얀 털은 살짝 발광(0.3)해 어두운 동굴에서도 하얗게 보인다. 애니메이션: 대기·걷기·달리기·구르기·망치·물총·피격·쓰러짐·줍기·냄새·짖기·승리(+interact). `yorkie.js` 삭제, 갤러리는 몰티즈와 모든 동작 버튼.
- 동작 표 `ACTIONS`를 `player/movement.js`로(갤러리가 Rapier 없이 씀): 구르기 0.4 s(GDD §3.1, 구르는 내내 무적), shoot·faint·pickup·victory 추가(cheer → victory). 하트 0이면 faint 동작, 줍기는 pickup 동작.
- 방 모듈 `dungeon/modules/`: 공통 서술자(`room.js`: `{ name, cols, rows, size, spawn, sockets{N,S,E,W}, obstacles, build(G, origin, theme) }`, 좌표는 모듈 최소 모서리 기준 m), `RoomSmall` 14×14(기둥 2·바위 1·수정 4), `RoomLarge` 24×20(기둥 4·바위 3·수정 4), `Corridor` 6×4. `dungeon/layout.js`: `attach(from, side, mod)`(소켓 정렬), M1 고정 배치 RoomSmall → Corridor → RoomLarge, `layoutCells`·`placement`·`moduleAt`, `buildLayout`. 문 폭 2칸(4 m).
- `world/cave.js` = 공통 동굴 빌더: 모든 모듈의 칸을 합쳐 셸 하나를 지으므로 소켓이 맞닿는 곳만 벽이 열린다(진짜 문). 지역 테마(`THEMES.moss`), 기둥·수정 헬퍼. 바닥·천장 충돌체는 칸 줄마다(암반 밑에는 바닥이 없어 길찾기가 바깥을 걷지 않음).
- 가림: 아래쪽 벽을 3칸 길이 조각(`caveWall`)으로 나누고, 조각 뒤 암반 윗면 2칸도 같은 조각에 넣었다(카메라에서 보면 벽 바로 뒤 주인공은 벽과 그 뒤 암반에 함께 가려진다). Island의 occluder 페이드가 이제 벽 조각에도 걸리고, 시선을 머리와 엉덩이 두 줄로 검사한다. 천장·위쪽 벽은 계속 숨김.

### 2026-11-01 · M3 아이템
- 데이터: `data/items.js`에 덩굴(속도 14 m/s, 문구)·방패(느려짐 ×0.5, 막힌 동물 1.2 m 튕김)·약초 문구, 물총 `wet: 3`(맞은 뒤 3초 젖음), `START`(망치+물총, GDD §11.1), `CHEST_LOOT`(약초 3·덩굴 3·방패 3·수정 조각 2[3~5개]; 가진 도구·꽉 찬 약초는 빼고 뽑음). 순수 규칙 `combat/loadout.js`(Q 순서 = items의 tool 순서 water→vine→mask, 가진 것만 돌기·덩굴 3/5초·방패 들기 2초·대기 4초(놓거나 시간 끝부터)·앞쪽 120° 판정·약초 +2 상한·`grant`), `core/rng.js`(mulberry32 + `subSeed`), `dungeon/loot.js`. `core/run.js`에 owned·tool·herbs·seed.
