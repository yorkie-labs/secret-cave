# 2026-11-07 · 엔딩을 3D 컷신으로 (Ending cutscene)

요청: "앤딩씬을 어떻게 만들면 좋을까? 바로 크레딧 나오는 것은 너무 휑함" → 제안한 구성 승인 ("엔딩 구성 좋네 적용해줘").

## 결정
- 인트로와 거울처럼: 인트로가 햇빛 → 어둠으로 떨어진다면, 엔딩은 어둠 → 햇빛으로 나온다. 인트로의 숲·동굴 입구 무대를 다시 쓴다.
- 약 40~50초, 레터박스 + 자막(인트로와 같은 방식), 건너뛰기, 엔딩 테마(해방감 → 잔잔한 크레딧 곡).

## 장면
1. 빛 속으로 — 터널 끝 하얀 빛으로 달려 나가며 화면이 빛으로 가득
2. 햇빛 아래 — 처음 떨어진 숲의 동굴 입구 앞, 눈을 깜빡이고 기지개. "멍멍! 드디어 탈출했다!"
3. 동굴의 변화 — 뒤돌아본다, 땅이 살짝 울리고 입구의 보라빛이 꺼지며 평범한 동굴로
4. 함께한 것들 — 망치·물총 내려놓기, 가방에서 모은 수정 조각이 반짝, 얻은 별(실제 기록)이 하늘로
5. 길 떠나기 — 해 질 녘 언덕길로 걸어가고 카메라가 하늘로. "그리고 다시 새로운 모험을 찾아 떠났어요."
6. 크레딧 — 노을 숲 풍경 위로 천천히 올라감
7. 떡밥 — 어두운 동굴 안 작은 보라 조각이 반짝 → "THE END…?" → 결과 화면
