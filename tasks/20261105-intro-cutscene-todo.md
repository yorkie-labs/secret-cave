# 2026-11-05 · 인트로를 3D 컷신으로 (Intro cutscene)

요청: "시작 이야기보기 버튼이 어색해, 새롭게 시작할 때 인트로 화면이 나오면 좋겠어" →
"카드로 이모지와 나오는 것도 어색".

## 결정
- 새 게임 → 인트로 자동 재생 (배선은 세계 축소 작업에서 `playIntro(onDone)` 하나로 처리)
- 이모지 카드 대신 **게임 엔진 안의 3D 컷신** + 화면 아래 자막, 위아래 검은 띠(레터박스), 건너뛰기 버튼
- 장면 (GDD §2.1 프롤로그):
  1. 햇살 비치는 숲 위, 몰티즈가 걸어간다 (카메라가 천천히 따라감)
  2. 땅의 이상한 발자국 → 냄새 맡기 → 따라간다
  3. 거대한 동굴 입구. "멍? 여기는 어디지?"
  4. 쿠구구궁! 땅이 흔들리고 무너진다 → 아래로 떨어짐 (화면 흔들림, 먼지)
  5. 어둠 속 빛나는 눈들 (늑대·토끼·여우·사슴 실루엣)
  6. 망치와 물총을 집어 든다. "좋아! 반드시 여기서 나갈 거야!" → 그대로 게임 시작 (싱크홀 바닥)
- 약 30~45초, 언제든 건너뛰기. 배경음 + 효과음.

## 설계 (만든 그대로)
- 입구는 그대로 `story.playIntro(onDone)` 하나(새 게임·처음부터·메뉴의 이야기 보기, 이어 하기는 안 거침). 카드(`#prologue`)는 지움
- `src/ui/introTimeline.js`(순수): 장면 6개 0–7 / 7–13.5 / 13.5–19.5 / 19.5–26.5 / 26.5–34 / 34–42.5 s, 자막 11줄(각 ≥ 2.5 s, 22자/초 타자), 소리 신호(음악 분위기 `introDay`·`introCave`·`introDark`·`introBrave`, 효과음 `chirp`·`glimmer`·`twinkle` 새로)
- `src/ui/intro.js`: 게임 렌더러, 자기만의 `THREE.Scene` + `stage('day')`. 구멍이 가운데인 고리 땅(가까울수록 촘촘, 멀리 언덕), 길, 숲(Polyfork 나무 7종 + 풀·꽃·고사리·버섯은 인스턴스), 언덕 속 동굴 입구, 문턱 뚜껑 7조각, 수직굴, 아래 방(지름 28 m). 시계 `t`의 함수라 다음 줄·건너뛰기·`seek`가 같은 길
- 메인 루프는 `story.view`가 있으면 그 프레임만 그림(게임은 멈춤). 게임 키는 `G.input.muffled`로 막힘
- 끝: 검정으로 → `onDone`(게임 시작 or 메뉴) → 검정이 걷힘. 기하·재질·텍스처·빛·인트로 전용 모델 원본을 놓음
- 레터박스 `--bar`: 가로 2.1:1, 세로 휴대폰 0.82:1, 최소 42 px. 건너뛰기 ≥ 36 px(휴대폰 가로), 44 px(그 밖)
- 인트로 모델은 새 게임일 때 부팅에서 미리 받음(프로덕션은 CDN)

## Review
- 만든 것: 이모지 카드(`#prologue`) 대신 게임 렌더러 안의 3D 컷신 42.5 s, 장면 6개(숲 7 s · 발자국 6.5 s · 동굴 입구 6 s · 무너짐·낙하 7 s · 어둠 속 눈 7.5 s · 망치와 물총 8.5 s), 자막 11줄(각 2.5 s 이상, 타자 22자/초), 레터박스, 건너뛰기 ▶▶·Esc, 클릭·탭·Space·Enter = 다음 줄. 끝나면 검정 → 게임은 지금처럼 싱크홀 입구로 떨어짐(메뉴에서 보면 메뉴로)
- 함께 고침: 손 닿는 동물을 빨리 한 번 누르면 두 번 휘두름. 뿌리: `pointer.js`가 공격 명령을 "휘두르는 그 순간 버튼이 눌렸나"로 지움 → 한 번 휘두른 명령(`swung`)은 다음 걸음에 버튼이 놓였으면 사라짐. `w7-rabbit.js`의 `pointer.cancel()` 둘을 지우고 휘두르기 수를 세는 확인 둘(옛 코드로 되돌려 돌리면 2번 휘둘러 FAIL, 고친 코드 PASS)
- 확인: `npm test` 243 통과(새 `test/intro.test.js` 9개), `npm run build` 통과. 새 시나리오 `w8-intro.js` 네 가지: 기본 22/22(건너뛰기 → 입구, 메뉴 다시 보기 Esc → 메뉴, GPU 기하 338 → 인트로 중 468 → 338, 텍스처 14 → 26 → 14), `full` 10/10(장면·자막 순서, 42.5 s, 입구), `continue` 3/3(이어 하기는 인트로 없음), `mobile` 세로 9/9·가로 9/9. 콘솔 오류 없음
- 전체 시나리오 한 번(포트 5192): 31개 실행 모두 통과, 단 `w7-combat`이 한 번 "물총 밀림 0.94 m(> 1.0 기대)"로 실패 → 다시 두 번 38/38(물총 타이밍, 이번 변경과 무관한 흔들림). `full.js` 83/0(인트로 Space 한 줄 → 건너뛰기 → 끝까지 완주, 797 s)
- 스크린샷: scratchpad `shots/intro/`(장면마다 `intro-1-forest` … `intro-6-tools`, `w8-mobile-portrait`·`-landscape`)
- 남은 것: 헤드리스 소프트웨어 렌더라 실제 휴대폰의 프레임 속도는 못 봄(숲 나무 ~120그루 + 인스턴스 잔풀, 그림자 1장). 딸이 볼 때 자막 속도·길이 의견 받기
